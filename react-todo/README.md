# Todo List — React (useState + события)

Учебный проект по частям 3–4:
- `useState`, функциональное обновление
- Управляемые инпуты
- Списки, key, условный рендер
- Локальное vs глобальное состояние
- Колбэки через пропсы

## Возможности

- Добавление задач с приоритетом (высокий / средний / низкий)
- Отметка выполненности
- Редактирование (двойной клик или 💾)
- Удаление
- Фильтры: все / активные / выполненные
- Фильтр по приоритету
- Поиск по тексту
- Сортировка: по дате / по алфавиту
- Прогресс-бар
- Массовые операции: отметить все, удалить выполненные, очистить всё
