# Каталог студентов — учебный проект по React

Реализация материала из частей 1–2:
- JSX, выражения, тернарники, className, инлайн-стили
- Компоненты и пропсы
- Деструктуризация, children, key
- Композиция компонентов
- Рендер списков через `.map()`

## Структура

```
src/
├── components/
│   ├── Header.jsx       # шапка
│   ├── StatCard.jsx     # карточка статистики (+ icon)
│   ├── StudentCard.jsx  # карточка студента (+ аватар, отличник)
│   ├── StudentList.jsx  # список карточек
│   ├── SkillsList.jsx   # список навыков (вынесен)
│   ├── Badge.jsx        # цветной бейдж
│   └── Footer.jsx       # футер
├── data/
│   └── students.js      # данные
├── App.jsx              # сборка всего приложения
├── index.css            # глобальные стили
└── main.jsx             # точка входа
```

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173
